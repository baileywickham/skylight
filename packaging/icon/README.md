# App icon

- `icon-1024.png` — the master: the "Desktop Skylight" concept, an ivory
  skylight frame (with Mac traffic-light dots on its top rail) opening onto a
  Bliss-style desktop wallpaper. Generated by GPT-6 Astra
  (`codex exec -m gpt-6-astra`) with Codex's `image_generation` tool, then
  masked to a macOS squircle. Raw generation: `source-gpt6-astra.png`;
  the other composition Astra produced: `source-gpt6-astra-alt.png`.
- The concept came from asking Astra for eight name+computer-use ideas and
  picking its top-ranked one.
- Rebuild the iconset + icns from the master:

      for s in 16 32 128 256 512; do
        sips -z $s $s icon-1024.png --out AppIcon.iconset/icon_${s}x${s}.png
        sips -z $((s*2)) $((s*2)) icon-1024.png --out AppIcon.iconset/icon_${s}x${s}@2x.png
      done
      iconutil -c icns AppIcon.iconset -o AppIcon.icns
